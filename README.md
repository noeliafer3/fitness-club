# Fitness Club Gym | Web de gimnasio

Web de una sola página (scroll) para un gimnasio ficticio, hecha con HTML, CSS y JavaScript sin frameworks. Diseño propio en Canva.

**Demo:** https://noeliafer3.github.io/fitness-club

## Funcionalidades
- Menú fijo que se vuelve sólido al hacer scroll, con el enlace de la sección activa resaltado
- Menú desplegable en móvil
- Sección de cuotas con tres planes y sección de servicios sobre un mismo fondo
- Formulario de contacto con validación en el cliente y envío real con [Formspree](https://formspree.io), sin necesidad de backend
- Botón que abre en una pestaña nueva el PDF con el horario de actividades
- Enlaces a las redes sociales (Instagram, Facebook y X)
- Animaciones de aparición al hacer scroll
- Responsive (móvil y escritorio) hecho con Flexbox, y accesible: HTML semántico, navegación con teclado y soporte de `prefers-reduced-motion`

## Estructura
index.html · css/style.css · js/main.js · img/ · fonts/ · pdf/

## Ejecutar en local
Abre `index.html` en el navegador o usa la extensión Live Server de VS Code. Para probar el envío del formulario es mejor usar Live Server o la web publicada.
